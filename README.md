# Dark Legacy

Ein Spielsystem für **Foundry Virtual Tabletop 14**.

## Installation

1. In Foundry VTT **Spielsysteme installieren** öffnen.
2. Diese Manifest-URL einfügen:

   `https://github.com/Muwak77/dark-legacy-system/releases/latest/download/system.json`

3. **Installieren** wählen und das System anschließend beim Erstellen einer Welt auswählen.

## Aktualisieren

Foundry VTT erkennt neue Versionen über dieselbe Manifest-URL. Öffne die Systemverwaltung und wähle bei Dark Legacy **Aktualisieren**, sobald eine neue Version angeboten wird.

## Hinweise

- Dark Legacy benötigt Foundry VTT 14.
- Die Änderungen der einzelnen Versionen stehen im [Changelog](CHANGELOG.md).
- Dieses Repository enthält die öffentlichen Installationsdateien und Releases.
